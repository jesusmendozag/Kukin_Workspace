# Kukin: app móvil

La documentación completa (arquitectura, cómo ejecutar y pruebas) está en el [README principal](../README.md).

Comandos rápidos:

```bash
npm install
npm run dev           # versión web de desarrollo
npm run android:sync  # compila y copia al proyecto Android
npm run android:open  # abre Android Studio
npm run android:apk   # genera el APK de depuración
```
